# Implementation status

Framework bootstrap in progress. No scientific feasibility conclusions yet.

Implemented: reproducible bounded candidate generation, outcome schema with explicit
unknowns, conservative label routing, trajectory-group splits, action distances,
MLP factory, immutable sample writes, evidence fingerprint gate, system audit.

Pending simulator acceptance: dependency installation, task inventory, RGB/proprioception
smoke test, ten-repeat deterministic replay, full controller/task snapshot restoration.

Pending after simulator gates: expert replay, task-specific safety/progress extractors,
resumable branch collection, pair audit, calibration-only threshold selection,
three-seed scorer fitting and evaluation. These are deliberately not represented as
completed experiments or fake successful scripts.
