# 实验框架与边界

当前实现对应前序清单的工程基础，不代表完整前序实验已经完成。

## 模块分工

| 模块 | 职责 | 当前状态 |
|---|---|---|
| env_adapter | 固定官方 LIBERO 版本、任务、初态、动作约束、双相机 | 已接入真实环境 |
| snapshot | 从同一初态重放动作前缀，恢复控制器及任务演化 | 正确性基准；非恒定时间直接快照 |
| candidate_sampler | 四类扰动，各四个；不含 reference | 已测试；边界采用截断高斯重采样 |
| branches | 相同快照、候选与公共后缀，独立结果文件及续采检查 | 已实现接口；需要任务验收 gate |
| outcome_extractor | 明确缺失值的结果结构 | 任务特定进度、接触、安全判据待实现并审计 |
| labeler | 严格等价、任务等价、危害、不确定 | 待真实标签审计；姿态采用四元数角距离 |
| datasets | 稳定 ID、轨迹级划分、禁止覆盖 | 已测试 |
| scorers | 动作距离与最小 MLP 工厂 | 训练、FAN近似、校准及评估 CLI 待实现 |

## 数据协议

每个候选保留 task_id、trajectory_id、state_id、candidate_id、seed、
动作块、公共后缀及验收指纹。结果使用 status 区分运行错误与真实失败。
object_pose 为固定物体顺序的 [N,7] 数组：x,y,z,qw,qx,qy,qz。
未知安全状态不是安全；缺少必要证据的样本归入 ambiguous。

初始随机动作重放通过后仍不开放采集。需要在两个任务的接触丰富专家轨迹上
检查快照，人工核对成功与安全判据，再生成 collection_approved=true 的证据。
该字段是程序门槛，不是科研有效性的自动证明。

## 后续执行顺序

1. 完成随机动作初态与中间重放检查，保存真实误差。
2. 从官方任务列表选取抓取放置与抽屉交互各一个，准备对应演示。
3. 实现演示 HDF5/XML 导入与成功重放；审计初始状态、控制器、动作时序。
4. 实现快速快照并与前缀重放基准比对，覆盖夹爪、接触和任务状态。
5. 确认任务特定结果提取器与人工标签审计流程，再启动约 800 个分叉。
6. 在轨迹级固定拆分上完成距离基线、FAN式近似、动作MLP与状态MLP评估。
7. 依据预先记录的决策阈值报告证据，不预设阳性结果。

主研究方案中的 FERA-Attack / FERA-Align 是未来阶段。
主方案 FAR 与“大距离但等价比例”的条件分母不同，分析阶段必须分别命名、
报告分母；不能把 P(大距离|等价) 与 P(等价|大距离) 混用。

## 远端与本地工作流

在远端形成一批可测试修改，运行对应检查，提交 remote main；
通过 Git bundle 拉到本地并 fast-forward，再 push origin main。
scripts/sync_from_remote.ps1 提供这一同步流程，拒绝本地脏工作区。
认证由本机 SSH 配置或 askpass 提供，脚本不保存密码。
原始数据与运行日志可以单独同步到本地 outputs，默认不推送。
